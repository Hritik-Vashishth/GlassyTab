Browser colors

Generate a Chrome theme from this wallpaper for your tabs, toolbar and address bar.

To apply: extract the downloaded ZIP, open chrome://extensions, enable Developer mode, click Load unpacked, and select the Wallpaper-Colors folder. Keep GlassyTab enabled too.

Chrome requires a separate theme installation. After changing wallpapers, download and install the new matching theme again. Browser colors do not switch automatically.
